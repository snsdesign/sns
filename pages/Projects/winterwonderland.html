Project

Winterwonderland.

This project was all about completely changing the vibe of an existing video only via VFX. Color grading, background replacement, roto-scoping and transitions all part of this project.

First I cut out the walking man via roto-scoping, also known as just masking. After that I replaced the background. This was done via Adobe Photoshop. Here I added the snow. Once that was done, I made the shot feel colder too, via color grading.

After that I added the snow. This was done in Adobe After Effects via the particles tool. The last step was creating the transition from the original video to the new one. I did this via a simple wipe effect.
